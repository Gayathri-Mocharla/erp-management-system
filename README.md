# ERP Management System

A full-stack ERP Management System built using MERN Stack.

## Live Website

Frontend:
https://erp-management-system-phi.vercel.app/

Backend:
https://erp-management-system-v04d.onrender.com

---

## Features

- User Login & Signup
- Employee Management
- Inventory Management
- Sales Management
- Reports Dashboard
- MongoDB Atlas Database
- CRUD Operations
- Responsive UI

---

## Project Setup

### Frontend

```bash
cd frontend
npm install
npm run dev
```

### Backend

```bash
cd backend
npm install
node server.js
```

---

## Environment Variables

Create `.env` file inside backend folder:

```env
MONGO_URI=your_mongodb_connection_string
JWT_SECRET=mysecretkey
```
